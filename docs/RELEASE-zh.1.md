# Composa 1.4.0-zh.2 — 简体中文公开测试版

基于上游 Composa 1.4.0 的简体中文社区版本。免费下载和使用，项目代码采用 MIT 许可，保留原作者及第三方版权声明。

选择 `win-x64.zip`，完整解压后运行 `composa.exe`。运行时和模型随包提供，无需另装 .NET。`sha256sums.txt` 用于检查下载完整性。

## 本次变化

- 汉化菜单、工具选项、调整、滤镜、Camera Raw、图层样式、快捷键和常用提示。
- 采用图像编辑常用中文术语，保留字体、文件名和用户内容。
- 使用独立设置及恢复目录，可与英文版并存。
- 默认关闭上游自动更新；手动下载按钮明确提示官方英文版。
- 保留上游功能测试，增加中文菜单执行、名称保护和工程保存/读取测试。

已有 277 项汉化检查及 Windows 界面/启动验证。本次发布的源码构建、上游测试和新增测试结果见仓库 Actions。复杂 PSD/RAW、大文件及长时间编辑仍需更多用户实测；第三方技术诊断可能保留原文。

欢迎通过 Issues 报告漏译、显示问题及兼容性问题。
